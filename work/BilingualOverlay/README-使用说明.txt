中英对照悬浮窗 1.1.0
=====================

快速开始
--------
安装版：双击 BilingualOverlaySetup.exe，确认安装。程序会安装到当前用户目录：
%LOCALAPPDATA%\Programs\BilingualOverlay

绿色版：解压 BilingualOverlay-Windows.zip 后双击 BilingualOverlay.exe。

启动后，悬浮窗默认位于当前屏幕右上方。在聊天框、网页输入框或编辑器中输入
文字，停止约 0.6 秒后会显示中英对照。上次位置会自动保存。

主要功能
--------
1. 中文自动翻译为英文，英文自动翻译为中文；也可在设置中固定翻译方向。
2. 长文本自动换行，可在原文或译文区域滚动查看。
3. 鼠标位于悬浮窗上时，Ctrl+滚轮可快速调整字号。
4. 拖动悬浮窗可改变位置；窗口会保持在显示器工作区内。
5. F8：暂停或重新开启监听。
6. F9：重新显示、复原，并关闭鼠标点击穿透。
7. 双击悬浮窗可隐藏；托盘图标可重新显示。

快捷键
------
Ctrl+Alt+T：优先翻译当前选中文字；没有选中文字时使用剪贴板。
Ctrl+Alt+F10：打开设置。
Ctrl+Alt+H：打开翻译历史与收藏。

以上三个快捷键可在“设置 > 快捷键与启动”中修改。快捷键必须包含 Ctrl、
Alt、Shift 中至少一个，且三个快捷键不能重复。F8、F9 为固定快捷键。

翻译历史与收藏
--------------
点击悬浮窗标题栏的历史按钮，或按 Ctrl+Alt+H，可打开历史窗口。

历史窗口支持：
- 查看最近翻译，最多保存 500 条；相同原文和译文会合并为最新一条。
- 搜索原文或译文，并筛选“只看收藏”。
- 收藏或取消收藏常用句；清空非收藏时，收藏会保留。
- 复制所选译文、删除单条记录、清空非收藏记录。
- 将当前筛选结果导出为 CSV。CSV 文件带 UTF-8 BOM，包含时间、原文、译文、
  来源和收藏状态。

历史默认开启，可在“设置 > 历史与隐私”关闭。也可设置“每次启动时清空未收藏
记录”。历史、收藏和设置均保存在本机，不会上传。

集中设置
--------
无需手工修改配置文件。设置窗口中可统一调整：

显示与窗口：字号比例、窗口宽高、透明度、全屏自动隐藏、点击穿透、位置锁定。
翻译服务：本地/在线模式、翻译方向、联网超时、服务检查、更新地址。
快捷键与启动：三个自定义快捷键、当前用户登录后自动启动。
历史与隐私：历史开关、启动清理、程序排除列表、打开数据/程序目录、清空缓存。

所有设置保存后立即应用。设置会尽量同时写入：
%LOCALAPPDATA%\BilingualOverlay\settings.json
以及程序目录的 settings.json。若一个位置不可写，会使用另一个位置。

隐私与排除程序
--------------
程序通过 Windows 辅助功能接口读取当前焦点输入框或选中文字，不记录每一次
键盘按键。密码框、密码管理器，以及标题含“密码 / Password / 无痕 /
InPrivate”等敏感窗口会自动跳过。

“程序排除列表”每行填写一个程序名，例如 notepad.exe。命中后不读取文字。
“仅本地词库”模式会完全禁止翻译网络请求。

历史开启时，翻译原文、译文、来源、时间和收藏状态会写入本机 history.json。
关闭历史或设置启动时清理可减少本地留存；历史窗口中的删除和清空操作会同步
更新本地文件。

安装、升级与卸载
----------------
安装程序会创建开始菜单和桌面快捷方式，并登记 Windows 当前用户卸载入口。
升级或重新安装只覆盖程序文件，不会删除 settings.json、history.json、收藏、
窗口位置或独立的用户数据。

卸载入口位于开始菜单。卸载时可选择：
- “是”：同时删除设置、历史与收藏。
- “否”：保留个人数据，便于以后重新安装。
- “取消”：停止卸载。

卸载程序会在当前进程退出后删除自身和安装目录中的程序文件。

版本更新
--------
在“设置 > 翻译服务”填写更新清单的 HTTPS 地址，然后点击“检查更新”。
更新清单示例：

{
  "Version": "1.1.1",
  "DownloadUrl": "https://example.com/BilingualOverlaySetup.exe",
  "Sha256": "64位十六进制SHA256",
  "Notes": "更新说明"
}

更新下载必须使用 HTTPS，必须提供 64 位 SHA-256，且有 200 MB 大小限制。
只有下载文件的 SHA-256 与清单一致时，程序才允许启动更新安装包。

当前构建尚未使用正式代码签名证书。发布给其他用户前，建议用 sign.ps1 配合
受信任的 PFX 证书或证书指纹执行 SHA-256 签名和 RFC3161 时间戳签名，以表明
发布者身份，并降低 Windows 或杀毒软件的误报概率。

多显示器与高 DPI
----------------
程序使用 Per-Monitor V2 DPI 感知，并在旧版 Windows 上自动回退。设置窗口和
历史窗口支持缩放，四个设置标签页在窄屏或高缩放下可滚动。

窗口支持常见显示缩放。副屏拔插、分辨率或 DPI 改变后，如果保存位置已不可见，
程序会自动将悬浮窗移回当前屏幕工作区。

自定义词句
----------
dictionary.tsv 可通过记事本编辑，每行格式：
中文[TAB]英文

glossary.tsv 是术语优先表，格式相同；在线翻译时会尽量恢复指定译法。
保存后，在设置窗口点击“保存并应用”或重新启动程序生效。

无法读取文字时
--------------
少数程序不向 Windows 提供输入框文字。此时可先选中文字并按 Ctrl+Alt+T；
若仍失败，可复制文字后再按该快捷键。

单独按方向键、Ctrl、Shift 等不会反复触发查询。相同内容会使用缓存，连续输入
时不会重复请求。

数据目录
--------
设置：%LOCALAPPDATA%\BilingualOverlay\settings.json
历史：%LOCALAPPDATA%\BilingualOverlay\history.json
窗口位置：%LOCALAPPDATA%\BilingualOverlay\window-position.txt
安装目录：%LOCALAPPDATA%\Programs\BilingualOverlay

恢复鼠标操作
------------
开启点击穿透后，鼠标会直接穿过悬浮窗。按 F9，或在托盘图标菜单中关闭
“点击穿透”即可恢复。
